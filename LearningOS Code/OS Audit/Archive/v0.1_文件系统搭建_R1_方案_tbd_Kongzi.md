---

## 二、规范体系总览

遵循 Specification-Driven Engineering 原则：

```
Constitution (最高规范 — 项目级)
    ↓
PRD (产品规范 — 模块级)
    ↓
Architecture (系统规范 — 模块级)
    ↓
ADR (决策规范 — 模块级)
    ↓
Engineering (代码实现)
```

错题整理系统作为第一个落地子模块，在子模块内建立 PRD → Architecture → ADR 的完整规范链。

## 三、文件系统设计

```
错题整理系统/
│
├── OS Audit/                       # 与审核 Agent 交互目录（已有）
│   ├── README.md
│   ├── audit_log.md
│   └── Archive/
│
├── Spec/                           # 规范体系目录
│   ├── PRD.md                      # 产品规范（Product Spec）
│   ├── architecture.md             # 系统规范（Architecture Spec）
│   └── adr/                        # 决策规范目录
│       └── adr-001-data-model.md   # 第一条 ADR
│
├── src/                            # 源码目录（空骨架）
│   ├── __init__.py
│   ├── core/                       # 领域层
│   │   └── __init__.py
│   ├── cli/                        # CLI 层
│   │   ├── __init__.py
│   │   └── commands/
│   │       └── __init__.py
│   └── utils/                      # 工具层
│       └── __init__.py
│
├── tests/                          # 测试目录（空骨架）
│   ├── __init__.py
│   └── conftest.py
│
├── data/                           # 运行时数据库（.gitignore 排除）
├── .gitignore                      # 排除项
├── requirements.txt                # 依赖（仅 pytest）
└── README.md                       # 项目说明
```
