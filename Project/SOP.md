## Sprint 2 · 错题整理使用场景

### 场景 1：录入一道错题

**你要做什么：** 孩子的卷子上有一道错题，要录入系统。

**做法：** 对 Agent 说：

> "帮开心录入一道错题。数学，五年级上，分数加法。题目是 3/4 + 1/2 = ?，她的答案是 1，正确答案是 5/4。原因是概念不清。"

Agent 会校验知识点是否合法，然后录入。

---

### 场景 2：批量导入（扫描件 / MD 文件）

**你要做什么：** 把扫描好的卷子 PDF 或手写的 MD 文件转成错题记录。

**步骤：**

1. **扫描卷子为 PDF**（扫描仪或手机扫描 App）

2. **PaddleOCR 转 MD**（一次性安装后，每次执行一条命令）
   ```bash
   paddleocr --image_dir 扫描件.pdf --output 输出目录 --format md
   ```
   这步是过渡方案。后续系统会内置 OCR，届时你直接给 Agent PDF 即可。

3. **或者直接写 MD 文件**——按以下格式手写错题（每道题一个 `## ` 标题）：

   ```markdown
   ## 3/4 + 1/2 = ？❌

   - **错误答案：** 1
   - **正确答案：** 5/4
   - **原因：** 概念不清

   ---

   ## 2/5 + 3/10 = ？❌

   - **错误答案：** 4/10
   - **正确答案：** 7/10
   - **原因：** 计算错误
   ```

   每条错题之间用 `---` 分隔。`❌` 标记不可省略（系统用它识别错题条目）。

4. **交给 Agent 处理**——对 Agent 说：

   > "把这个 MD 文件里的错题录入系统，开心，五年级上。"
   
   或直接在 CLI 运行：
   ```bash
   python -m src.cli.main add-raw 错题.md --student 开心 --grade 五年级上
   ```

   Agent 会用 AI 拆题、逐条确认、写入正确位置。CLI 模式会先预览识别结果再确认。

---

### 场景 3：开始复习

**你要做什么：** 开心的分数加法错了 3 次了，要复习。

**做法：** 对 Agent 说：

> "帮开心复习分数加法。"

Agent 会返回 AI 分析结果——错误归纳、引导问题、3 道同类题。你把这些内容读给孩子。

**多学科说明：** 英语/语文的错题也是一样操作。Agent 会自动识别科目。
如果 Agent 默认选了数学，说明：
> "这是一道英语题，用英语复习。"

或直接在描述中指明科目：
> "帮开心复习英语的一般现在时。"

---

### 场景 5：查看学习概览

**你要做什么：** 想知道开心最近的整体学习情况。

**做法：** 对 Agent 说：

> "开心最近学得怎么样？"

Agent 会输出概览：活跃知识点数、已掌握数、待复测知识点、本周新增错题、最薄弱知识点。

---

### 场景 6：今天该复习什么

**你要做什么：** 不知道今天该复习哪个知识点。

**做法：** 对 Agent 说：

> "今天该复习什么？"

Agent 会根据各知识点的错题数、复测期、错误趋势，推荐 1-3 个最适合今天复习的知识点。

---

### 场景 4：判题

**你要做什么：** 孩子做完了 Agent 出的 3 道题，要录入结果。

**做法：** 对 Agent 说：

> "第 1 题对了，第 2 题错了，第 3 题对了。"

Agent 会逐题录入、自动判定：全对→已复习，有错→错的自动变新错题。

---

### 场景 5：查看学习情况

**你要做什么：** 想看看开心最近数学错题集中在哪。

**做法：** 对 Agent 说：

> "开心的错题情况怎么样？" 或 "开心分数加法还有多少没复习的？"

Agent 会返回列表或画像摘要。

---

### 场景 6：在 Obsidian 里看错题本

**你要做什么：** 打开 Obsidian，看完整的错题集、打印。

**路径：** `LearningOS Users/开心/data/错题整理/错题集/` → 按学科/年级/知识点浏览。

这里的文件是 Markdown 格式，可以直接看、改、打印。不需要通过 Agent。
